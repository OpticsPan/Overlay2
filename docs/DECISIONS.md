# 管理决策记录

## DEC-001：采用轻量仓库管理基础

- 日期：2026-10-27（Asia/Shanghai）。
- 背景：仓库为空，所有者确认暂无待接入资料，先建立管理基础。
- 采用方式：main 基线与短期分支、PR 审阅、版本化管理文档和 GitHub 模板。
- 考虑的替代方式：仅用聊天记录难以随代码追溯；完整发布平台和长期多分支流程目前缺少实际代码与团队需求。
- 版本规则：初始化保持未发布；首个业务版本以运行和验收证据决定。
- 需求记录：先记录已确认的管理需求；业务定位、技术栈和首版范围保留待确认。
- 当前限制：尚未配置 CI、分支保护、自动发布或许可证。
- 复查时机：首次接入代码、出现协作者或准备首个发布版本时。
