## 管理规则

- 编号采用 REQ-001、REQ-002 等递增格式，已分配编号不复用。
- 本台账记录已批准的范围和验收状态；尚未明确的想法先保留为待确认事项或草案。
- 状态：草案 → 待确认 → 已确认 → 进行中 → 待验收 → 已验收；取消的需求保留并注明原因。

- 已实现不等于已验收；验收需关联 PR/提交和可复核的证据。
- 范围变化先更新验收标准和变更原因，再继续实施。
